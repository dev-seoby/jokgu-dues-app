# 하루FC 회비관리 대시보드

조기축구팀(하루FC) 회비를 엑셀 대신 관리하기 위한 총무 전용 SaaS 웹 대시보드.

> 원래 앱인토스(Apps in Toss) 모바일 미니앱으로 시작했으나, 실사용이 주로 PC에서 이루어지는 점을 반영해
> 사이드바 메뉴 구조의 데스크톱 웹 대시보드로 전환함. 앱인토스 트랙은 별도로 재검토 가능.

## 스택

- Vite + React 19 + TypeScript
- [당근 Seed Design System](https://seed-design.io) (`@seed-design/react`) — UI/버튼 전반에 사용
- 데이터는 현재 `src/data/mock.ts` 목업, 추후 Supabase(Postgres) 연동 예정

## 화면 구성 (좌측 사이드바 메뉴)

- **홈** — 잔액, 이번달 입출금, 최근 내역, 미납 현황 요약
- **거래** — 입출금 내역 조회/필터/검색, 입금·출금 등록 (영수증 이미지 첨부 지원)
- **회원관리** — 회원별 당월 납부 상태 토글, 일괄 납부처리, 활동/휴회 전환, 회원 추가
- **리포트** — 월별 순증감 차트, 월별 미납 회원 목록, 카테고리별 지출

## 총무 1인 관리형

회원 로그인 없이 총무가 혼자 관리하는 구조. 회비 결제는 결제 SDK 연동 대신
수동 기입 + 영수증 이미지 첨부 방식을 사용. 카카오톡 개별 알림은 미지원 (수동 전달).

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # tsc -b && vite build
npm run lint      # oxlint
```
